# UJI 预处理机制对照协议 v1

日期：2026-10-28，Asia/Shanghai。本对照仅解释已经看过的 UJI 现象，不属于独立确认，不改变外部参考审计协议或任何已冻结数据、代码及结果。

## 固定范围

选取旧真实设计阶段的 seed 300、305、308，每种子包括 dispersed/clustered 两布局及 strong/mixed_weak 两幅度，共 12 个旧目标。选择这些种子是事后机制取样，不能据其异常比例推断总体发生率。基线复用 `results/workshop/real` 的原始参考、系数、配置、数据哈希及 y/λ。

保留旧 1000 行、原顺序、原噪声、原响应和原 λ。按旧元数据的原 CSV 行号和 WAP 列号取出原始 RSSI 子样本。只读检查输入指纹；不使用旧真实经度响应选择变量、分组或生成新 y。

## 对照臂及坐标映射

| 臂 | 列关系与新 X | 参考调用 |
| --- | --- | --- |
| baseline | 原最终 float64 X | 原双参考复用 |
| final_float64_exact | 对最终 X 的列字节作精确同列检查，保留最早列 | 没有删列则复用基线；若意外删列，仅记录 protocol-review，不额外拟合 |
| A_raw_exact | 在原保留列的原始 RSSI 子样本中做精确同列去重，保留最早列；新 X 直接选旧最终 X 的这些列 | 有变化时双参考；无变化时复用基线 |
| B_near | 仅由旧最终 X 按相对回归残差≤1e-12建立近比例组，按列顺序留锚；每成员直接对锚复核，允许反号 | 有变化时双参考；无变化时复用基线 |

原始 RSSI 相同不意味着两列经过旧处理后的 float64 字节相同。A、B 均记录最终 X 中的锚点比例 `a_j`、每成员残差、原 WAP 身份和被删除列。A 的组由原始 RSSI 确定，比例只用于公开最终数值表示；B 的组只使用 X，不看真系数或参考结果。

对任意旧系数 w，映射后的锚点系数为 `theta_g=sum_j(a_j*w_j)`。分别保存真系数和两套旧参考的映射。公开旧无噪声信号与映射信号的 RMSE、实际预测残差与三角界。单例比例为 1。

两个对照始终保持旧 y 和 λ，未重新标准化保留列。近似表示及非单位比例可能改变目标；不宣称严格等价、不把结果写成修复了原目标。即使比例为±1，组内正负抵消也使某个给定表示的 L1 范数下降，不能忽略。

令 `A=sum_j |a_j*w_j|`、`C=A-||theta||_1`、`S=sum_j(|a_j|-1)|w_j|`，记录 `||theta||_1-||w||_1=S-C`。比例误差界为 `E=sum_j ||a_j|-1| |w_j|`，从而范数变化位于 `[-E-C,E-C]`，绝对变化不超过 `E+C`。同时报告乘 λ 后的惩罚变化、旧/映射原始目标与表示误差，不将其当完整解集界。

## 评价对象与参考资格

基线原变量 F1 保持原样。降维 F1 仅相对映射净系数在预定 τ 下的支持；另存“组中含任一真变量”、合并了多少真变量、净效应抵消和丢失的身份。原变量 F1 与降维 F1 不是同一任务，不能相减后称恢复改善。

新问题的双参考沿用旧 `fit_references`：sklearn 循环 CD 和 skglm，各自从零拟合，共同归一化 gap≤1e-10，20 秒返回后软预算及固定库容差阶梯。支持阈值为 1e-6、1e-4。共识仍只表示数值共识，分歧和低浮点秩均不证明数学多解。

每臂分开记录 `accuracy_eligible`（双参考精度、对偶可行、返回状态及观察预算均通过）与 `reference_consensus`（再满足系数、目标、两阈值支持和符号一致）。所有有资格的参考均保留其评分，不按共识筛选；未运行或异常的资格记为未判定并附原因。

## 预算、保存与边界

A/B 最多 24 个新问题、48 次公共参考调用；skglm 内部容差重算另计。总墙钟预算 600 秒，在问题之间检查；进行中的库调用不能硬中断。预热、原始数据/映射准备、参考、额外诊断及写出分别记录。预算不足的臂保留为未运行，不按是否消除分歧选择性删除。

每个新问题在调用前持久化两个公共调用槽的预留。异常不释放预留且不自动重试；部分库尝试数未知时明确记未知，不能按零计。完整参考缓存可只读恢复，不重复记新调用。若进程中断而总墙钟账本不完整，自动续跑停止并要求检查预算。

运行前锁定本协议、配置、新 driver、冻结数据/参考 helper 和所选旧输入的哈希。原始旧文件只读。无删列复用基线时必须逐位核对 X/y/λ 与旧问题一致，不能把复用记作新拟合。新结果保存在 `results/uji_preprocessing_control_v1`。

本对照只能说明固定样本及处理下的机制和目标变化。它不替代外部设计的独立验证、不构成新算法、不保证组评价恢复真实变量，也不取消旧 30/40 个原坐标参考不确定标签。
