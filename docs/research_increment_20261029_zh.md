# Lasso 变量选择可靠性的研究增量

更新日期：2026年10月29日（Asia/Shanghai）  
新增实验完成日期：2026年10月28日

## 核心观点

在本研究的UJI半合成任务中，抽样后形成的近比例特征使Lasso的原变量选择对列输入顺序敏感。同一实现达到统一高精度后，可以得到几乎相同的训练拟合，同时返回不同的支持与恢复分数。研究由此聚焦于一个具体问题：**当多种变量表示具有接近的拟合质量时，如何理解和报告支持恢复结果？**

列顺序实验提供了保持数学目标和原变量身份的受控证据。结合此前的抽样诊断、预处理对照和外部验证，可以围绕变量表示的可区分性，组织求解精度、输出稳定性和统计恢复质量之间的关系。

## 列顺序实验带来的直接证据

实验使用全部40个旧UJI目标，以及新闻和基因各8个既有对照目标。每个目标采用原顺序与5个固定随机列排列，两套实现分别求解，输出逆映射回原坐标评分。数据列值、响应、真系数和λ保持不变。

主分析包含672个输出，另有112次原顺序重复用于核查。全部784个输出达到归一化对偶间隙≤1e-10及既定资格要求；112组原顺序重复与112组历史核对均通过。重复输出仅用于核查，评分范围来自预定的六种顺序。

主支持阈值τ=1e-6时，结果如下。

| 来源与实现 | 目标数 | 支持变化目标 | F1变化目标 | F1极差严格超过2个百分点 | 最大F1极差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| UJI sklearn | 40 | 18 | 18 | 18 | 7.66个百分点 |
| UJI skglm | 40 | 26 | 25 | 21 | 9.63个百分点 |
| 新闻 sklearn | 8 | 0 | 0 | 0 | 0 |
| 新闻 skglm | 8 | 0 | 0 | 0 | 0 |
| 基因 sklearn | 8 | 0 | 0 | 0 | 0 |
| 基因 skglm | 8 | 0 | 0 | 0 | 0 |

UJI的支持变化分别覆盖sklearn的7/10、skglm的9/10种子块；F1极差超过2个百分点的事件分别覆盖7/10和8/10种子块。同一实现跨多个种子的重复现象，为后续机制解释提供了基础。每个种子内的四个条件、多个排列和两套实现属于配对观察。

此前双参考实验展示了不同实现之间的评分差异。本轮进一步观察到同一实现内部的变化，并保留了原变量评价对象，使列输入顺序成为可直接检验的实验因素。原顺序重复全部通过，也为本轮观察提供了重复性对照。

来源：[列顺序实验结果](column_permutation_findings_v1_zh.md)、[独立验收](column_permutation_review_v1.md)。

## 拟合接近与变量评分变化同时存在

最大F1范围案例中，skglm的六个输出从0.727273变化到0.823529，极差约9.63个百分点，最大支持对称差为5个变量。六个输出之间的最大拟合RMSE差约8.49×10⁻¹¹，最大目标值绝对差约2.22×10⁻¹⁶。各项最大值分别计算，可能对应不同输出对。

这一案例将评价对象的差别具体化：优化证书描述当前目标的求解精度，训练拟合描述输出信号，支持恢复评分则依赖原变量身份。不同系数表示可以在前两个层面非常接近，并在第三个层面产生可见差异。这里的F1范围对应六个已观测输出。

此前对40个UJI目标的事后配对分析也呈现相似特征。两实现的平均F1仅相差约0.079个百分点，逐目标绝对差的平均值却达到1.244个百分点；15个评分有差异的目标中，两实现各有8次和7次取得较高分数。配对差异在总体平均中相互抵消，因此，逐目标范围、差异幅度和事件覆盖能为平均F1补充实质信息。

来源：[列顺序实验结果](column_permutation_findings_v1_zh.md)、[事后描述性分析](../results/posthoc_interpretation_20261028.json)。

## 近比例结构连接抽样过程与输出变化

矩阵审计发现，代表性WiFi特征在完整数据与训练池中可区分，部分行子样本却只留下同一行的稀少检出，形成近比例列。这个观察将机制定位到实际抽样和预处理后的设计。

列顺序实验在拟合前固定原坐标中的近比例组。主阈值下，全部变化坐标均落在这些非单例组内。按各目标的变化坐标并集累加，sklearn为组内27、组外0，skglm为组内45、组外0；同一原变量可在多个目标中重复计数。

这些结果支持一种机制解释：近比例方向允许系数在相近拟合之间重新分配，列顺序所影响的求解路径与最终变量表示相关。原先完整双参考共识通过的10个UJI目标，在本轮六种顺序下均保持支持和评分稳定；全部事件集中于原先未决的30个目标。原有资格分层因此获得了本轮扰动实验的描述性支持。

来源：[UJI矩阵审计](uji_preprocessing_audit_v1.md)、[列顺序实验结果](column_permutation_findings_v1_zh.md)。

## 预处理对照说明表示粒度的作用

三个事后选定种子的12个目标中，原问题的完整参考共识为2/12。原始RSSI精确去重后仍为2/12，近比例分组留锚后达到12/12。留锚每个设计归并3至8个原坐标；4/12个目标被删除的坐标包含生成真系数，其信号通过比例映射转到锚点。

这一对照展示了采用较粗表示时获得数值共识的效果及其解释代价。映射后的评价以组净效应为对象。在该坐标下，12个目标均选中了全部净真信号，平均仍有约4.67个误选项，精确支持恢复为0/12。

因此，报告可以分别讨论两个问题：选择何种表示粒度能够稳定描述信号，以及在给定表示下还存在多少统计误选。列顺序实验保留原变量身份，预处理对照则展示归并身份后的效果，两类证据共同说明变量解释粒度的重要性。

来源：[预处理对照](uji_preprocessing_control_findings_v1_zh.md)、[事后描述性分析](../results/posthoc_interpretation_20261028.json)。

## 外部结果明确当前结论的适用范围

此前新闻和基因来源各36个确认目标均取得完整双参考共识，没有支持或F1分歧；本轮从既有确认清单中按编号选择的各8个目标，在六种列顺序下也保持稳定。基因的响应种子共享固定设计矩阵，本轮对照属于既有目标上的机制跟进。

这些稳定结果使研究重点集中到UJI抽样后产生的局部近冗余结构。与之相配的研究结论是：在这一具体设计机制下，统一高精度输出的原变量评价仍会受到列顺序影响。列顺序实验提高了该案例的证据完整性，外部实验则提供了所测条件下的稳定参照。

来源：[外部参考审计](reference_audit_findings_v1_zh.md)、[列顺序实验结果](column_permutation_findings_v1_zh.md)。

## 报告观点与组织方式

建议将报告中心表述为：**相关设计下Lasso支持恢复评价需要结合目标精度、变量表示稳定性和统计恢复质量。UJI案例显示，抽样形成的近比例结构可使同一高精度实现对列顺序敏感，进而改变原变量恢复分数。**

正文首先以列顺序实验呈现核心现象，用逐目标F1范围和拟合差展示评价后果。随后介绍抽样产生的近比例结构及变化坐标的位置，再用预处理对照解释表示粒度和剩余误选。外部稳定结果与原共识分层放在正文中，共同交代现象覆盖。早期合成容差实验提供求解精度与支持稳定关系的背景。

结果展示以完整目标集合为基础，配合逐目标差异、种子块覆盖和重复核查。原变量评分与映射净效应评分分别呈现，支持变化与F1变化分别计数。这样的组织能够保留每一阶段的新增信息，并让读者沿着设计结构、计算输出和评价结果理解研究主线。

当前增量是同一目标与原变量坐标下的受控证据、变化位置的机制核对，以及评分后果的量化。文献定位继续使用[列顺序相关研究核查](column_order_related_work_v1.md)，将这些具体证据作为贡献讨论的基础。
