# 特征相关性与 Lasso 的实测发现

2026 年 10 月 28 日（Asia/Shanghai）完成。主网格 180 次、真实数据 27 次全部达到归一化对偶间隙 1e-6；18 项正确性测试和六个代表性复现检查通过。数值只对应本项目的分组设计、参数、种子和实现。完整逐次记录与统计见 `results/summary.json` 和 CSV。

## 三个研究问题

**相关性提高会增加本组问题的求解成本。** ρ=0→0.9 时，九组算法/λ组合的五种子配对时间比中位数为 12.9–76.1。以相对 λ=0.05 为例，ISTA 中位求解时间为 0.106→7.263 秒，FISTA 为 0.134→5.433 秒，CD 为 0.034→0.560 秒。样本 Hessian 条件数中位数为 33.0→2650.7；总体块条件数则是 1→181，二者不可混用。性能变化还包含活跃集、有限样本及相对 λ 规则的影响。

**FISTA 的实际优势依赖实例与精度。** 在低相关设计上，高精度 FISTA 可慢于 ISTA；高相关时 FISTA 在两种近端方法中更快。60 次 FISTA 求解中有 50 次观察到相邻检查点目标上升，共 3114 次；这是每五步检查下的计数。CD 在本组合成实现中最快，但这既包含算法结构，也包含 BLAS 与 C99 内核的具体常数。真实数据最佳验证参数下，三种子的求解时间中位数为 ISTA 1.691、FISTA 0.805、CD 0.283 秒；其中一个划分 FISTA 快于 CD，不能把 CD 排名推广为普遍定理。

**优化误差与统计恢复不等价。** 以 CD 相对 λ=0.05 为例，系数误差中位数从低相关 0.076 增至高相关 0.170；各算法求解同一目标后的统计指标接近。弱正则化 λ/λmax=0.01 是重要反例：ρ=0→0.9 时，系数误差 0.169→0.222，而 F1 0.061→0.157。真实支持 recall 的中位数均为 1，估计非零数从 634 降至 235，precision 提高，解释了 F1 的相反方向。不能用单个指标概括“恢复一定更差”。

## 核查、复现与计时边界

- 与参考目标的最大归一化绝对差：合成 3.17e-12，真实 1.15e-10；全部记录的对偶约束比未超过 1。
- 六个重新生成数据的代表性求解均复现，最大系数差约 7.9e-15。
- 把检查间隔从 5 改为 20：最终精度的四组排序 4/4 相同，三种精度合计 10/12 相同；粗精度时间受采样粒度影响。
- 主合成诊断开销中位占比：ISTA 22.3%、FISTA 22.2%、CD 15.2%。精确 SVD 中位 0.435 秒另计，独立启动图为近端方法加回该成本。
- 支持阈值 1e-8/1e-6/1e-4 下，48/180 次运行 F1 有变化，最大绝对变化 0.00396。
- 真数据三种子的测试 MSE 中位数均约 0.75905，单位为 log1p(shares) 的平方。没有真实支持，不能声称真实恢复率。

## 结论的主要限制

只有五个合成种子，IQR 是实例间离散程度；没有每个固定实例的独立多次测时。真支持限制在不同组，未覆盖同组多个真信号。相同相对 λ 不等于相同绝对 λ。仅一个真实数据集，随机划分不能推断未来预测效果。CPU 为共享环境且未独占绑定，微小时间差不可过度解释。没有实现热启动、筛选、重启或 GPU 扩展，也没有提出新算法。
