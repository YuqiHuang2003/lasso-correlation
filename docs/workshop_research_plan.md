# Lasso 相关设计的 Workshop 短论文研究计划

更新日期：2026 年 10 月 28 日，Asia/Shanghai。目标先定位为 workshop 或短论文，中文工作稿暂按 4–5 页正文组织；具体格式由之后选定的征稿要求决定。现有课程报告与冻结结果继续作为先导材料。

## 研究问题与候选贡献

原主题保持“特征相关性对 Lasso 求解效率与稀疏恢复的影响”。短论文收窄为：**在不同相关几何下，固定求解容差何时已经足够支持变量选择，何时仍不足？多算的时间改变了什么？**

候选工作是一次有边界的容差适用性审计，联结支持恢复与计算成本。它不预设“统一对偶间隙不可靠”，也不预设“提前停止总能节省计算”。普通设计与预先定义的弱信号、近共线设计均应完整呈现。

预期贡献需要落在一个新且有用的经验结论及其解释上：明确在哪些设置，进一步缩小间隙只改善数值精度；在哪些设置，仍改变变量选择；以及现有低成本诊断能否区分这些情况。该经验结论的新颖性尚待与最近邻工作逐项核对，不把问题表述本身当成创新。

## 已有证据与存储限制

| 已有证据 | 可支持的判断 |
| --- | --- |
| 360 个合成固定目标，4 方法共 1440 次求解 | 运行次数不等于独立统计重复，每格只有 5 个数据种子 |
| 360/360 个目标的四种方法在主阈值下最终支持完全一致 | 当前设置没有显示达到 1e-6 间隙后广泛存在跨求解器支持分歧；这也不证明支持与精确最优解一致 |
| 三种基本方法共 1080 条轨迹，1e-4 至 1e-6 间只有 9 条的 TP/FP/FN 计数变化 | 提示恢复计数可能较早稳定，但计数相同不能证明变量索引相同；变化中既有改善也有变差 |
| 最终系数、真支持与各检查点的汇总指标已保存 | 可以复查终点支持与恢复曲线 |
| 参考求解只存证书，中途检查点不存变量索引或系数 | 无法从旧结果精确恢复参考支持与逐变量数值错误；须补充有针对性的运行 |

轻量核查入口为 `scripts/audit_workshop_feasibility.py`，输出 `results/workshop/feasibility.json`。它只读旧结果，不重新求解。当前观察不能推出“1e-4 普遍足够”，也不能推出可部署的提前停止准则。

## 最近邻工作与必须区分的内容

| 工作 | 已覆盖的问题 | 本计划需要进一步核对的差异 |
| --- | --- | --- |
| [Kumar 等，相关设计支持恢复数值研究](https://doi.org/10.1080/03610918.2022.2050392)，2024 卷期、2022 在线 | 相关性、稀疏度、信噪比、系数分布、估计器与模型选择 | 单纯再画恢复相图没有充分区分；候选关注同一估计目标内部的精度与成本 |
| [Gap Safe，Fercoq 等](https://proceedings.mlr.press/v37/fercoq15.html)，2015 | 用对偶间隙安全排除零变量，并研究有限识别 | “gap 与支持识别相关”不是新结论，安全筛选应是比较基线 |
| [Bastounis 等，可信特征选择 II](https://arxiv.org/abs/2312.11429)，2023 预印本 | 条件数、有限精度、支持计算可信性与相关随机设计 | 不把病态反例、支持稳定或可信计算的一般想法宣称为新方法 |
| [Walwil 与 Fercoq，平滑对偶间隙停止准则](https://doi.org/10.1007/s12532-025-00284-0)，2025 | 不同停止量的比较、误差界与运行成本 | 本计划采用普通 Lasso，需说明变量选择端点与通用最优性判断的具体区别 |
| [skglm](https://jmlr.org/papers/v26/24-0008.html)，2025 | 现代稀疏模型求解与软件基准 | 现代实现作为真实基线；不能把基本 CD 对 Python 近端实现的优势当成机制创新 |

## 三类支持与可证伪假设

分别定义生成模型的真支持 `S_true`、给定数据和 λ 的 Lasso 最优支持 `S_lambda`，以及检查点的数值支持 `S_num(t)`。只有最优支持唯一且可可靠判定时，才用单一 `S_lambda`；`p>n` 本身不代表多解。实际保存的高精度参考支持仍是数值参考，不能仅凭很小的目标间隙称其为已证明精确。

先检验两个假设，允许全部被否定；第一项为主问题，第二项用于解释：

1. 在普通设计中，部分计算成本发生在支持已与可靠参考一致之后；该比例随算法、惩罚与几何变化。
2. 弱信号和小非活跃 KKT 裕量区域，需要更严格容差才能得到与参考一致的支持；单一相关系数不能充分解释这个差异。

低成本诊断仅作为可选探索，不作为这篇经验短论文必须提出的新方法。若进一步比较诊断与固定容差，须在独立确认数据上评价，并计入诊断成本。

主要指标为支持对称差、符号差异、与真值的误选/漏选、首次观测到参考支持匹配的时间、最后一次观测不匹配后的时间及剩余求解成本。它们只针对预定检查点，不保证检查点之间或之后永不变化。F1 保留为补充，不能用两次 F1 相减当作数值错误分解。按变量共同记录真值、参考、当前三种状态，分别统计数值步骤造成的错误和偶然修正；这些记账关系本身不是新定理。

## 最小新增实验

第一步为独立小规模试跑，保存高精度参考系数、首次穿越预定 gap 阈值时的系数，以及每个预定检查点的支持位图与符号；仅存阈值穿越点不足以分析中途反复。参考不明确的案例标记为“参考不确定”。保存开销单列，主要计时阶段使用一致的记录方式。

试跑选择块相关与 Toeplitz 两类设计，覆盖两种支持布局、强信号与预定弱信号区间。先用少量预先固定的代表组合和独立种子检验可辨识信号，不扩展成全因素大网格；也不靠反复挑选病态案例制造结论。近乎退化案例作为压力测试单列。

确认阶段冻结设置，关键比较使用独立于探索阶段的种子。恢复比例应给出区间；例如若希望最坏情况下 95% 区间半宽约 0.1，需要约 100 次独立重复，而不是把同一实例的四种算法计成四份样本。计时重复与数据重复分别统计。

真实设计使用公开连续回归数据的特征矩阵，预设稀疏系数并生成模拟响应，使支持真值可知。原始真实响应仅支持预测或优化验证，不充当支持恢复真值。数据划分、标准化、弱信号设定与 λ 在确认前锁定。

基础算法用于机制轨迹，scikit-learn/skglm 用于现代求解器端点。机制比较应使用相同框架或充分消融；记录基本运算量与端到端时间。库本地容差映射到统一后验 gap，不默认为数值相同就精度相同。Gap Safe 的安全零变量排除覆盖、与参考支持匹配、真实支持误差分别记录；安全排除部分零变量不等于完整支持或真支持已确定。超时报告完成率与未完成状态。

探索试跑的新增 CPU 墙钟预算先限 2 小时，并计入原项目总预算。若没有可区分的新信号或清楚的文献差异，先修改问题，不自动扩跑。

## 进入短论文写作的条件

继续推进需要同时满足：存在与最近邻工作可清楚区分的结论；至少在两类设计及真实设计模拟响应上得到独立验证；解释不依赖真支持作为可部署算法输入；现代基线、诊断成本、失败案例与不确定性均完整记录。

如果常规设置一直表现稳定，应如实报告适用范围。只有极端构造反例、已有原理的重复展示或缩短旧报告，都不足以自动构成新的 workshop 贡献。没有证据支持新诊断优于现有方法时，不加入方法创新主张。

中文短稿围绕一个主结论组织：问题与已有工作、审计定义、两到三组关键结果、边界与实践含义。课程版完整推导和大网格移入补充材料，作者信息仍按当前要求留空。
