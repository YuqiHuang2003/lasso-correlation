## 固定处理步骤

1. 去除列名首尾空格；排除 `url`（标识符）与 `timedelta`（官方标记为非预测变量）；使用其余 58 个预测变量。`shares` 只作为目标。
2. 将目标定义为 `log1p(shares)`，降低长尾计数对平方损失的支配。这是本项目的建模选择，不是原始数据的目标单位。主要 RMSE 与 R² 在这个对数尺度报告，不暗示等价于原始分享数误差。
3. 对每个固定划分种子先保存训练、验证、测试的原始行索引，再做任何标准化。采用 60%/20%/20% 的随机划分（前两部分向下取整），三个固定种子为 0、1、2，每次训练、验证、测试样本数为 23,786、7,928、7,930。
4. 只用训练集计算特征均值、总体标准差以及目标均值，验证和测试沿用。零方差列使用可记录的安全尺度处理。训练目标中心化后，截距通过目标均值恢复，截距不加入 L1 惩罚。
5. 对每个划分的训练数据计算 `λmax=||Xᵀy||∞/n`。先用参考求解器在 20 点对数网格 `λ/λmax ∈ [0.001,1]` 上按验证 MSE 选择最优点，再取该点和网格上最近的两点作为三档算法比较值。三种算法共用这三档 λ、数据与零初值，独立求解约 27 次（3 个划分 × 3 个 λ × 3 个算法）；筛选阶段的参考求解另计。测试集不用于选择 λ、预处理或优化超参数。
6. 若不进行合并重拟合，最终报告已选 λ 在原训练模型上的测试误差并明确训练规模。若进行训练加验证重拟合，则重新在合并集拟合预处理参数，记录新增运行与绝对 λ 的选择约定。
7. 输出每次求解的 λ、精度、时间、状态、非零系数数、验证误差及测试误差。真实数据没有已知真值支持集，不计算“真实支持恢复率”。

## 解释限制

随机划分提供固定公开表格上的离线预测基准，不模拟未来新闻部署。新闻统计中存在基于关键词分享数或关联文章分享数的特征；它们在真实发布时是否可得、是否涉及未来信息，应在部署研究中另做时间审计。本项目不声称验证了真实时间预测性能或新闻传播因果关系。[UCI 特征说明](https://archive.ics.uci.edu/dataset/332/online+news+popularity)

真实设计矩阵中的相关性由数据决定，不能像合成实验一样控制；因此真实数据只验证算法在一个实际设计上的求解和预测一致性，不用于识别“改变 ρ 的因果效应”。高相关或线性依赖也可能使系数不唯一；参考求解检查优先使用原始目标值与对偶证书，不能只要求两份系数逐项相等。
