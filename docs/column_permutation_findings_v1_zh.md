# 列顺序扰动 v1：同一目标、原变量坐标下的结果

日期：2026-10-28，Asia/Shanghai。研究主题仍为“特征相关性对Lasso求解效率与稀疏恢复的影响”。本阶段是既有目标上的机制跟进，不是新增独立真实数据确认。此前外部推广未通过的结论保留。

## 主要结果

**在所测UJI目标中，仅改变列输入顺序，同一实现通过共同高精度检查后的原变量支持与真支持F1仍会变化。** 这比此前删列/聚合对照更直接：数学目标、X的列值、y、λ、真系数和原变量身份都保持不变，输出逆映回原坐标后评分。

| 来源 / 实现 | 目标 | 主τ支持变化 | F1极差>0 | F1极差严格>.02 | 最大F1极差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| UJI / sklearn | 40 | 18 | 18 | 18 | 7.6577个百分点 |
| UJI / skglm | 40 | 26 | 25 | 21 | 9.6257个百分点 |
| news / sklearn | 8 | 0 | 0 | 0 | 0 |
| news / skglm | 8 | 0 | 0 | 0 | 0 |
| gene / sklearn | 8 | 0 | 0 | 0 | 0 |
| gene / skglm | 8 | 0 | 0 | 0 | 0 |

主τ=1e-6，F1范围及δ=.02/0/.01/.05的严格比较由TP/FP/FN整数计数的Fraction计算。支持变化不等于评分变化：skglm有26目标支持改变，其中25目标F1改变，21目标极差超过.02。完整τ=1e-4敏感性及全部逐目标结果保留于CSV/JSON，不只展示最大案例。

## 冻结输入、重复控制与完整性

旧UJI全部40目标（10seed×两布局×两幅度），news401/402与gene501/502各8目标（两幅度×两c）。外部按编号选择，非新确认。13份不同X：UJI10、news2、gene1；gene两个响应种子共用一份72×7129矩阵。

每X原序加5个固定随机排列（seed700–704），每target/实现另重复原序一次。为补齐此前仅12目标重复控制的覆盖缺口，拟合前将计划从696修订为784公共调用：672主输出+112重复QC。全部784条清单及实际排列、原坐标组、来源哈希均先准备后锁定。

- 784/784输出独立精度合格，无超时、未执行、未知部分调用或stage_stop；实际库拟合864次，固定容差阶梯额外调用另计。
- 112/112原序与历史参考核对通过；112/112当前原序重复QC通过。
- 精度按每输出原坐标归一化gap≤1e-10、可行性及20秒返回后软预算判断，不按跨实现共识预筛。
- 数值独立验收再生56旧目标、检查13份X、784输出、1568份双坐标证书；结构检查2,113,421及数值检查20,720均通过。
- 分析独立验收224个target/实现/τ条件、2240个事件状态、560个同实现seed块和280个跨实现并集状态，25,131项检查通过，不重载X、不拟合。

准备与运行计算墙钟合计56.533秒，含预热，在7200秒阶段软预算内；开发、人工停留和独立验收另计。该记录不用于求解器速度排名。

## 种子块及原有资格分层

块内4目标任一事件即块event，4个全无事件才no_event，其余未决；raw与重复QC限定状态分别保存。本轮QC全部通过，两层事件数字一致。

| 同一实现 | UJI支持事件seed块 | F1极差>.02事件seed块 | 未决 |
| --- | ---: | ---: | ---: |
| sklearn | 7/10 | 7/10 | 0 |
| skglm | 9/10 | 8/10 | 0 |

两个实现均触发预定的“同一实现至少2个UJI seed块”机制研究工作门槛。它不是显著性、独立推广或发表门槛；不把两实现、五排列及配对幅度当独立样本。

原先完整双参考共识的10个UJI目标，两实现在这六种顺序下均无支持/F1变化；所有事件都位于原先未决的30目标中。因此，本轮没有发现原共识合格集被这些排列推翻。有限清单的稳定仍不证明任意顺序稳定、唯一性或统计恢复正确。

## 机制位置与代表案例

原X残差阈值1e-12的近比例组在拟合前固定，没有在每个排列后重新按首列分组。主τ下，各目标内变化坐标并集求和：sklearn组内27、组外0；skglm组内45、组外0。这个计数可跨目标重复同一原WAP，不能当独立变量样本数。全部本轮变化都落在已定义非单例组内，支持限定的近比例机制解释，不证明它是所有顺序效应的唯一原因。

最大F1范围案例为`uji_seed303_clustered_mixed_weak`的skglm：六输出F1为.727273至.823529，极差18/187≈.096257；主支持最大两两对称差5，最大系数L∞差约.8651。六输出间最大拟合RMSE差约8.49e-11、最大目标绝对差约2.22e-16；各最大值不必来自同一对输出。原序重复与历史核对都通过，未删列或换成组评分。

sklearn最大案例为`uji_seed304_dispersed_strong`，F1极差17/222≈.076577，最大支持差3。案例按最大范围事后展示，发生频数以全40目标为准。

## 能支持什么、仍缺什么

本轮排除了“分歧只存在于两个实现之间”及“评分变化仅因删列/聚合换了评价对象”的解释，给出了同实现、原变量坐标的受控证据。它没有覆盖完整最优/近最优解集，不证明精确数学多解，也不把观察到的最高F1顺序当可部署调参方案。

外部两个来源仍稳定，原共识通过的UJI目标也稳定。工作性继续条件已满足，适合保留并深入定位这个限定机制；本阶段不自动增加排列、换seed寻找正例或启动其他实验。发表增量仍需与已有坐标顺序、近最优表示及可信支持研究比较，不能把“顺序影响优化”重新命名为创新。knockpy官方实现已有拟合前随机列排列及逆映射处理；2026年去相关研究也有顺序例，但改变了正交化目标。直接近邻及差别见`column_order_related_work_v1.md`。
