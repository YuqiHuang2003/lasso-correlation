## 此次实际发现与建议

1. **近期发展需要补足，现已处理。** 仅到 2017 年的文献在 2026 年提交时较难充分体现课程所说的近期发展。本次核实并追加了 [Anderson acceleration of coordinate descent](https://proceedings.mlr.press/v130/bertrand21a.html)（2021）和 [skglm: Improving scikit-learn for Regularized Generalized Linear Models](https://www.jmlr.org/papers/v26/24-0008.html)（2025）。前者直接对应坐标下降加速，后者展示利用稀疏结构的工作集和模块化实现。两者只作综述，不新增主实验范围，不使用论文速度数字冒充本项目测量。

2. **计时必须同时呈现谱计算的影响。** 近端方法的 `L` 采用完整稠密 SVD；算法内部时间之外，独立调用还需承担这笔成本。现有分析区分 solver 与 cold-start，报告应分别说明。若只展示共享 SVD 后的 solver 时间而称为从数据到解的总时间，会误导读者。预处理、参考求解和验证筛选成本也应单列，不能混入基础算法的内部迭代排名。

3. **五个配对种子的 IQR 反映设计实例间差异。** 它不是固定实例多次测时的置信区间，也不能推导总体统计显著性。当前研究目标允许这种描述性比较，但措辞应使用“在这五个种子中”“中位数与四分位距”。相关性比较保留每个种子的配对关系，不仅比较两组无配对中位数。

4. **迭代上界与实测间隙曲线的量不同。** 经典 `O(1/k)` 和 `O(1/k²)` 控制真实目标残差，当前曲线记录的是可计算对偶间隙；不应仅凭图形斜率声称验证了最坏情形速率。可如实比较达到相同间隙精度的时间和迭代数量，并报告 FISTA 在检查点之间观测到的目标增加。每五步检查一次意味着并未观察所有内部迭代的振荡，不能报告为“全部目标上升次数”。

5. **优化精度与恢复关系应按固定目标比较。** 同一数据和 λ 下的三个精度检查点可以回答求解更准是否恢复更好。不同 λ 的最终恢复差异还含有正则化强度变化，不能归因于优化误差。真实数据没有支持真值；其非零数不等同于正确变量数。

6. **结果与代码来源检查已补强。** 再次核查当前 `run_study.py`，源码哈希已纳入 `.c`，环境已记录编译器版本，数值签名覆盖数据、算法、C 内核与运行脚本，复用时核对该签名；参考解已断言间隙和对偶可行性，验证筛选也检查精度。最终验收只需确认最终日志均携带相应签名并与冻结源码一致。报告或说明的改动不改变数值来源，无须因此重跑已通过的实验。

7. **公开数据的适用范围需准确。** 本次官方 CSV 为 39,644 行，UCI 当前网页为 39,797 行，使用数据文件哈希与实测行数。随机划分和与分享数相关的既有统计特征只支持离线预测验证；不能宣称已测试未来新闻预测。RMSE/MSE 的单位是 log1p(shares) 对应尺度，应在表注给出。
