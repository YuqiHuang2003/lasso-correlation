## 数学与控制变量检查

- 主网格为 360 个目标、四方法共 1440 次。绝对 lambda 为 `c * sigma * sqrt(2*log(p)/n)`，不随 rho、s 或 layout 改变；lambda_max 只作记录。因此没有重复第一版相对 lambda 与噪声同时漂移的混杂。
- 数据生成使用八个独立随机流。同种子设计分量、测试分量和高斯噪声实现跨结构配对；X 在 s/layout 改变时保持相同。支持在各布局内按 s 嵌套，前缀符号序列在布局间共用。分散布局每活跃组一个信号，集中布局每组五个信号。
- 固定单个系数幅度和 sigma 后，总信号方差随 s、rho、布局与符号抵消而变。这是本实验的条件性结构效应，不能写成固定全局 SNR 的比较。原始噪声先按 sigma 生成，之后 y 按训练均值中心化；报告的 iid 噪声方程描述生成阶段，中心化后的噪声带有去均值相关。
- 活跃 Gram 是 `X_S.T @ X_S / n`；不可表示分数为 `max(abs(G_ScS @ solve(G_SS, sign(w*_S))))`，与本目标缩放一致。全 Hessian 在中心化且 p>n-1 时奇异，所以不用其有限条件数。总体块信号方差 `(1-rho)*k + rho*(sign_sum)^2` 的作用域已明确；不能替代样本标准化后的实测方差。
- 特征 precision、recall、F1、FDR、精确支持、完整符号和活跃符号准确率定义正确。组支持指标另报真组数，避免把 s 个真组与 s/5 个真组的 F1 当作相同基准难度。数值非零阈值与额外硬阈值分开。
- UJI 先划分，再用训练集删除常量及完全重复列并拟合标准化；验证集选 lambda，测试集不参与选择。Leukemia 是固定平方损失优化设计，不声称二元标签的回归应用性能或未知真实支持恢复。

## 共同精度、失败与计时

- 四方法共用相同数据、lambda、零初始和未惩罚截距的中心化处理。原始/可行对偶目标及归一化间隙来自同一个未修改的证书函数。
- skglm 的本地子梯度停止量不等于归一化 gap。固定梯子 `1e-4 -> 1e-6 -> 1e-8` 每次从零拟合，最多三次；总 elapsed 包含所有尝试、后验证书、回调和包装成本。`iterations` 是各次外层工作集轮数之和，不能称完整 epoch。没有每目标八次拟合的代码路径。
- skglm 仅有起点及拟合端点。分析脚本同时检查方法名与标志位，排除其首次阈值曲线，正确。
- 基本方法在更新间检查时间，现代库只在拟合之间或返回后检查。现代超额状态与证书是否通过分开记录；所有超时/未达标输出保留。共同归一化 gap 使同一目标上的算法比较公平，但跨目标不等于相同绝对目标误差或相同系数误差。
- 汇总耗时仅用共同精度成功记录，同时保存全部终止点恢复与成功子集恢复。配对比较标注有效对数；五个种子的 IQR 是实例差异，不是计时置信区间。
- “cold_start_sec”仅是在 solver elapsed 上给近端方法加回 SVD；数据准备和一次性 C/JIT 设置另记。不能把它解释成全新进程的总启动时间。
