## 主问题与候选贡献

主问题是：**在固定数据与 Lasso 目标、两套实现均通过精度检查后，逐变量恢复评分是否依赖返回的系数表示；这种差异是否超过预先声明的评价容许差，以及参考准入与仅用 X 的分组评价各付出多少覆盖或解释代价？**

求解容差是参考资格的一个控制量，统计恢复与参考歧义共同服务这一主问题，不另起一个优化器性能故事。候选贡献限定为真实设计基准的可复核资格/覆盖/评价后果审计。多解、近最优支持多样性、KKT裕量与安全筛选均已有研究，不据此宣称新理论或新算法。

## 对象与准入分层

生成真支持 `S_true`、条件满足时的精确最优支持、数值参考支持、阈值输出支持和聚合支持分别命名。精确支持未被证明时不以数值共识替代；不一致也不直接证明数学多解。

1. **精度与预算可用（accuracy-eligible）：** sklearn循环CD与skglm均在返回后观测预算内完成，共同归一化gap≤1e-10，原始/对偶值有限且对偶可行。主要评分差在全部此类目标上计算，**不先筛共识通过者**。
2. **完整参考共识（consensus-accepted）：** 在上一层上增加系数L∞差≤1e-7、归一化原始目标差≤1e-9，并在τ=1e-6/1e-4均支持及符号相同。各失败条件分别记录，不能把未决目标合称多解。
3. 未达到精度或超额者保留，主要差值标为不可判断，不作差值为零、不从计划分母消失。

主要支持阈值τ=1e-6，τ=1e-4为敏感性。统计惩罚λ、迭代gap、阈值τ和float64精度分别控制。两参考从零独立拟合，共用同一X/y/λ及未惩罚截距的中心化处理。

来源与原始文件SHA使用既有下载快照。新闻许可CC BY4.0；基因来源页未明确再分发许可，原始数据仅本地处理、包中不分发。两来源不作难度匹配，不以n/p差异解释来源优劣；选择基于可复现来源可用性，不是随机抽取的数据集总体。

每个最终样本先删除精确常量列，再中心化与总体标准差缩放，保留所有其余列，不按20列截断、不自动删除重复/近重复。分明的随机流控制行、支持顺序、符号和高斯噪声；支持按均匀随机排列前5列选择，不添加人工布局块。

强信号全部±1；混合弱信号将有序支持第4个幅度改为0.25。σ=1固定。λ=cσ√(2log(p)/n)，c∈{0.5,1}，按最终n/p计算；同一目标的两方法使用同一绝对λ。相同source/seed在c和幅度条件间共享X、支持、符号与噪声；c变化不改变y，幅度变化只改变相应真系数。

预定工程先导：news seed400、gene seed500，每来源4目标，共8目标、16次公共参考调用。确认使用news401–409、gene501–509，每来源9个新seed、36目标；合计72确认目标、144次公共调用。先导与确认单独汇总；若协议不变可附全部80目标描述，不能将其当80独立设计。

## 实质评价后果

主要工作性容许差δ=0.02（绝对F1差，即2个百分点），并报告δ=0、0.01、0.05敏感性。该值是知晓旧UJI结果后、面向独立新实例的研究选择，**不是领域公认阈值或事先未见任何结果的选择**。s5的F1离散，必须同时报告TP/FP/FN与变量身份差，不能仅用是否越过δ放大效果。

主要统计单位为每来源的确认seed。一个seed的四条件中，只要任一精度可用目标ΔF1>δ，记为已观测实质事件；只有四目标均精度可用且均未越过δ，才记为已观测无事件。其余seed未决。报告事件/无事件/未决三类计数和全计划分母；目标级比例仅作配对条件的描述。固定X的基因结果是条件于该设计的响应/支持Monte Carlo，不是九份独立真实矩阵。逐条件区间只在每seed一条、明确可用分母下给出；不汇合两来源作总体概率推断。

次要离线检查：对同source/seed/幅度下两档c，以每参考的真F1分别定义最优c集合（比较容差1e-12）。分别记录最优集合相同、严格单一最优反转、涉及平局以及精度未决；不采用任意argmax打破平局。这是已知真支持的oracle评分，不是实际验证集调参或不同估计器的性能提升。

## 评价方案与机制对照

原坐标结果始终保留。比较单一sklearn输出、单一skglm输出、双参考共识并完整报告未决，以及仅用X定义近比例组后的评价。两解分数最小/最大只称已观测范围，不称完整解集上下界。

精确同列/反号列按存储float64逐位关系检查。近比例分组主相对回归残差≤1e-12，敏感性1e-10/1e-14；列顺序锚点、每成员直接对锚点检查，不依赖真β或解。高维来源使用分块候选扫描与直接残差复核，避免无说明构造整块p×p数组；诊断时间与内存分开记录。

组评分主真值为锚点坐标下净系数 `sum(a_j*beta_j)` 超过同τ的支持；另记录“组中含任一真变量”作为不同对象。报告非单例组、最大组、被合并真变量、净效应抵消及丢失的变量身份信息。不能把原变量F1与组F1直接当同一任务比较，也不能用合并全部特征制造稳定性收益。

UJI预处理审计另作为机制检查：比较展示三列关系在源训练池、旧1000行样本及新行子样本中的保持情况，记录精确重复、近比例和一般线性依赖，先只作矩阵诊断，不覆盖原问题。任何删列、聚合或ridge处理均是独立对照，写清目标/参数化变化。

新代码、配置、来源哈希及本协议在首次新增优化前锁定。记录单线程float64、每公共参考返回后20秒软预算、固定最大迭代及库容差阶梯。库调用不能硬中断，超额必须明确标记。预处理/分组、参考求解、额外诊断和写出分开计时。
